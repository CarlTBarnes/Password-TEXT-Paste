## Test Paste in RTL Password ENTRY

Folder contains small project to test if Paste is allowed by RTL using an ENTRY with PASSWORD attribute

Clarion Readme files say Paste was "fixed" June 4, 2021 in Clarion 11.1.13744 which was the first/gold release of 11.1.

I used this project to verify it is fixed in the final Clarion 11.1.13815 release and the Clarion 12 first release 12.13941.

By fixed I checked:
1. Ctrl+V Pasted the Password
2. Right-Click Popup Menu has Paste enabled and it worked
3. Right-Click Popup Menu has Copy disabled
